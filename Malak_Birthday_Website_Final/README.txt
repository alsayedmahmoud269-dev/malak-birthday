MALAK BIRTHDAY WEBSITE - FINAL

This version keeps the original first design and removes the quiz/question section.
The quiz is replaced by four interactive envelopes containing the four birthday messages.

Files
- index.html
- style.css
- script.js
- config.js
- assets/photos/
- assets/music/song.mp3

Setup in VS Code
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Put your photos in assets/photos and update their names in config.js.
4. Put your song at assets/music/song.mp3.
5. Open index.html with Live Server.

The countdown is disabled because birthday.date is null.
There is no quiz and no question section.
There are exactly four envelopes.
